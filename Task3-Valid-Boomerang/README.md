# WIX1002 Task 3 — Valid Boomerang

**Student:** GENGHONGBO  
**Matric:** 25007555  
**Problem:** [LeetCode 1037 — Valid Boomerang](https://leetcode.com/problems/valid-boomerang/)

The solution computes the 2D cross product of the vectors from the first point to the other two points. The three points form a boomerang exactly when the determinant is non-zero, meaning they are not on one straight line.

**Time:** O(1)  
**Space:** O(1)
